# animalsounds

``` r
library(animalsounds)
```

## Description of the package

The goal of animalsounds is to print a statement about the sound an
animal makes.

``` r
animal_sounds("dog", "woof")
#> [1] "The dog goes woof!"
animal_sounds("giraffe")
#> [1] "The giraffe makes no sound!"
```
